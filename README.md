# Chennai Rental Market Analyzer

A data pipeline that scrapes rental listings from MagicBricks and performs statistical analysis on Chennai residential rent distribution.

## Features

- Playwright-based dynamic scraping
- HTML parsing with BeautifulSoup
- Data cleaning and normalization
- SQLite storage
- Pandas-based analytics
- Rent distribution visualization

## Tech Stack

- Python
- Playwright
- BeautifulSoup
- SQLite
- Pandas
- Matplotlib

git clone https://github.com/yourusername/chennai-rent-analyzer.git
